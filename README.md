# Кейс-задача № 1

## Условие

Дан одномерный массив А размерности N. Найти сумму отрицательных элементов,
расположенных между максимальным и минимальным.

## Решение

Программа находит первое вхождение максимального и первого вхождения минимального
элемента массива. Затем суммирует все отрицательные элементы, стоящие строго между
ними (сами максимум и минимум в сумму не входят). Если max и min расположены рядом
или встречаются на соседних позициях, сумма равна 0.

Порядок обхода не зависит от того, какой из крайних элементов стоит левее:
границы упорядочиваются программой автоматически.

## Запуск

Python (версия 3.6+):

    python solution.py

После запуска введите размер массива, затем его элементы.

Пример:

    Введите массив через пробел: -5 2 -3 8 -1 -7 4
    Сумма отрицательных элементов между max и min: -1

## Проверка

| Массив                       | max / min позиции | Результат |
|------------------------------|-------------------|-----------|
| [-5, 2, -3, 8, -1, -7, 4]    | 8 и −7            | −1        |
| [3, -1, -4, 5, -2, 1, -8, 6] | 6 и −8 (рядом)    | 0         |
| [1, -2, -3, -4, 5]           | 5 и −4            | 0         |
